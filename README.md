# Java Food Ordering System 🍔

A console-based food ordering system developed in Java using Object-Oriented Programming concepts.

The project simulates a basic food ordering workflow with separate modules for users, food orders, billing, payments, and InstaMart.

## ✨ Features

- User management
- Food ordering
- Cart management
- Order management
- Billing
- Payment handling
- InstaMart functionality
- Console-based interaction

## 🛠️ Technologies Used

- Java
- Object-Oriented Programming (OOP)
- Data Structures
- IntelliJ IDEA
